# XOXO Game (Tic-Tac-Toe)

A clean, lightweight, and interactive Tic-Tac-Toe (XOXO) web application built using vanilla JavaScript, HTML5, and CSS3. 

## 🚀 Features
* **Interactive Gameplay:** Smooth X and O turn transitions with real-time win/tie detection.
* **Modern UI:** Styled with a polished aesthetic, utilizing custom layout design and visual assets (`pic.jpg`).
* **Completely Responsive:** Adapts flawlessly to desktops, tablets, and mobile screens.
* **Lightweight & Fast:** Zero external dependencies or frameworks—built entirely with native web technologies.

## 📁 Project Structure
The repository contains the following core files:
* `index.html` - The structural skeleton and layout of the game board.
* `style.css` - Custom styling, typography, colors, and responsive grid layouts.
* `script.js` - Core game logic including turn management, move validation, and win-condition checking.
* `pic.jpg` - Visual graphic asset used to enhance the interface design.

## 🛠️ Built With
* **HTML5** - Semantic elements for web structure.
* **CSS3** - Layout styling and responsive media queries.
* **JavaScript (ES6+)** - Game logic and dynamic DOM manipulation.
